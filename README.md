# Hópverkefni 1 – Vefforritun 1

## Keyrsla

Settu upp verkefnið og keyrðu þróunarþjóninn úr rót verkefnisins:

```sh
npm install
npm run dev
```

Parcel birtir forsíðuna á staðbundnum vefþjóni og endurhleður hana þegar skrám
er breytt. Til að útbúa framleiðsluútgáfu er hægt að keyra:

```sh
npm run build
```

CSS/Sass er yfirfarið með:

```sh
npm run lint
```

## Uppbygging

- `index.html` er forsíðan og undirsíður eru í `sites/`.
- `javascript/` inniheldur JavaScript, meðal annars virkni farsímavalmyndar.
- `pictures/` geymir myndir sem notaðar eru á síðunum.
- `styles.scss` er Sass-innkomuskrá sem raðar sameiginlegum stílum og
  síðustílum úr `styles/`.
- `styles/` inniheldur Sass-stíla fyrir grunn, valmynd, fót og hverja síðu.
  Sass er þýtt í CSS af Parcel þegar verkefnið er keyrt eða byggt.
- `efni/` og `fyrirmynd/` geyma verkefnisgögn og fyrirmyndarefni.
